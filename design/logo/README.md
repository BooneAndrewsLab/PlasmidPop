# PlasmidPop logo (option 4b)

Source: Claude Design project "PlasmidPop logo design"
(https://claude.ai/design/p/b308fd70-dd57-43bd-bf5a-ac62b6da235f). The files
here are the project's `export/` folder; the C2PA provenance `<metadata>` block
was stripped from the SVGs to keep them small.

Mark: lowercase "p" whose bowl is an open plasmid ring; red feature segment
after the gap, three ticks radiating from the opening. In the lockup the mark
stands in for the "p" of "plasmidpop".

Files

- plasmidpop-mark-light.svg — ink #201e1d + red #ec3013, for light backgrounds
- plasmidpop-mark-dark.svg — off-white #f3f2f2 + red, for dark backgrounds
- plasmidpop-mark-on-red.svg — off-white + ink, for red #ec3013 fields
- plasmidpop-lockup-light.html / -dark.html — mark + wordmark, self-contained
  (loads Archivo from Google Fonts; the in-app wordmark is pre-outlined instead)

Wordmark

- Font: Archivo, weight 700, width axis 88, letter-spacing -0.035em, lowercase
- Text: "lasmid" in ink, "pop" in red; mark placed 2px before with descender
  14px below baseline at 64px (mark size 92px)

Palette

- Ink #201e1d · Ground #f3f2f2 · Accent #ec3013

Scaling: at ≤32px use stroke-width 12–14 in the SVG (viewBox 0 0 64 64) for
legibility.

Where the logo is used in the app

- `public/favicon.svg` — mark, switches ink/off-white with `prefers-color-scheme`
- `public/icons/*.png` — PWA icons, generated by `scripts/make-icons.sh`
- `src/app/components/Logo.tsx` — header lockup (mark + outlined wordmark)
