# Sample files

Every file here is a **synthetic example**: invented sequences, nothing taken
from a catalogue, a paper or a database. They are plain GenBank files; download
them and open them in PlasmidPop with **File ▸ Open**, or drag them onto the
window. Each tutorial names the files it needs and the order to open them in.

| File                                                                                               | What it is                                                                                                                                                                                                                                                                                |
| -------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [pLig-Vector.gb](files/pLig-Vector.gb)                                                             | Circular 2,664 bp vector for the ligation exercises: `synthetic promoter`, `MCS` (EcoRI, PstI, BamHI, in that order), `synthetic terminator`, `AmpR` (a stand-in resistance gene, reverse strand), `ori` (a stand-in origin). EcoRI, PstI and BamHI cut it once each, all inside the MCS. |
| [Insert-EcoRI-BamHI.gb](files/Insert-EcoRI-BamHI.gb)                                               | Linear 819 bp: EcoRI site, the 783 bp ORF `synthORF1` (ATG to stop), BamHI site, with a few bases of padding. No other EcoRI, BamHI or PstI site.                                                                                                                                         |
| [Insert-PstI-BamHI.gb](files/Insert-PstI-BamHI.gb)                                                 | The same ORF with a PstI site where the EcoRI site was: the negative control.                                                                                                                                                                                                             |
| [Insert-EcoRI-EcoRI.gb](files/Insert-EcoRI-EcoRI.gb)                                               | The same ORF with an EcoRI site at both ends, for single-enzyme cloning and dephosphorylation.                                                                                                                                                                                            |
| [pGG-Expression.gb](files/pGG-Expression.gb)                                                       | Circular 2,857 bp Golden Gate expression vector for [Golden Gate](golden-gate.md): `KanR` (stand-in), `ori`, `synthetic promoter`, a `lacZ-dropout` between two BsaI sites, `synthetic terminator`. The slot asks for the overhangs `AATG` ... `GCTT`, the MoClo plant CDS pair.          |
| [GG-gene.gb](files/GG-gene.gb)                                                                     | Linear 702 bp `synthGene`, a plain ORF (ATG to stop) with no BsaI site and no Golden Gate ends, for [Golden Gate](golden-gate.md): the app designs its primers.                                                                                                                           |
| [pGG-Destination.gb](files/pGG-Destination.gb)                                                     | Circular 2,647 bp Golden Gate destination vector: `KanR` (stand-in), `ori`, and a `lacZ-dropout` between two BsaI sites.                                                                                                                                                                  |
| [GG-prom.gb](files/GG-prom.gb)                                                                     | Part 1, 106 bp, `synthetic promoter`, BsaI overhangs `GGAG` ... `AATG`.                                                                                                                                                                                                                   |
| [GG-cds.gb](files/GG-cds.gb)                                                                       | Part 2, 623 bp, `synthCDS`, a coding part without a stop, `AATG` ... `TTCG`.                                                                                                                                                                                                              |
| [GG-tag.gb](files/GG-tag.gb)                                                                       | Part 3, 55 bp, `synthTag` (a short linker and His tag ending in a stop codon), `TTCG` ... `GCTT`.                                                                                                                                                                                         |
| [GG-term.gb](files/GG-term.gb)                                                                     | Part 4, 96 bp, `synthetic terminator`, `GCTT` ... `CGCT`.                                                                                                                                                                                                                                 |
| [GG-broken-internal-BsaI.gb](files/GG-broken-internal-BsaI.gb)                                     | Part 3 with a third BsaI site inside it (54 bp).                                                                                                                                                                                                                                          |
| [GG-broken-duplicate-overhang.gb](files/GG-broken-duplicate-overhang.gb)                           | Part 3 whose right overhang is `AATG`, already taken by the promoter/CDS junction.                                                                                                                                                                                                        |
| [GG-warn-tag.gb](files/GG-warn-tag.gb), [GG-warn-terminator.gb](files/GG-warn-terminator.gb)       | A replacement pair for parts 3 and 4 that joins on `AATC`, one base from `AATG`: assembles, with a warning.                                                                                                                                                                               |
| [MC-L1-Destination.gb](files/MC-L1-Destination.gb)                                                 | Circular 1,572 bp level-1 destination vector for [Modular cloning](modular.md): `AmpR` (stand-in), `ori`, and a `lacZ-dropout` between two BsaI sites. Its backbone ends are `CGCT` and `GGAG`, which close a ring of MoClo plant positions.                                              |
| [MC-L0-Promoter-A.gb](files/MC-L0-Promoter-A.gb), [MC-L0-Promoter-B.gb](files/MC-L0-Promoter-B.gb) | Level-0 promoter parts (96 and 116 bp) for the MoClo position Promoter + 5′UTR, BsaI overhangs `GGAG` ... `AATG`. Alternatives to each other.                                                                                                                                             |
| [MC-L0-CDS-A.gb](files/MC-L0-CDS-A.gb), [MC-L0-CDS-B.gb](files/MC-L0-CDS-B.gb)                     | Level-0 coding parts (326 and 386 bp) for the position CDS, `AATG` ... `GCTT`: an open reading frame of 100 and 120 residues, ATG to stop.                                                                                                                                                |
| [MC-L0-Terminator.gb](files/MC-L0-Terminator.gb)                                                   | Level-0 terminator part, 92 bp, for the position 3′UTR + terminator, `GCTT` ... `CGCT`.                                                                                                                                                                                                   |
| [MC-wrong-position.gb](files/MC-wrong-position.gb)                                                 | A 106 bp part cut for Yeast Toolkit Type 3 (`TATG` ... `ATCC`): it fits no MoClo plant position, so the panel does not place it.                                                                                                                                                          |
| [GB-Vector.gb](files/GB-Vector.gb)                                                                 | Linear 1,506 bp vector for [Gibson](gibson.md), already linearised: `synthetic terminator`, `KanR` (stand-in, reverse strand), `ori` (stand-in), `synthetic promoter`. It starts with 26 bp that `GB-Insert2` ends in and ends with 28 bp that `GB-Insert1` starts with.                  |
| [GB-Insert1.gb](files/GB-Insert1.gb)                                                               | Linear 508 bp: the 28 bp vector overlap, `synthDomainA` (150 residues, ATG, no stop) and a 30 bp `linker` that `GB-Insert2` starts with.                                                                                                                                                  |
| [GB-Insert2.gb](files/GB-Insert2.gb)                                                               | Linear 449 bp: the 30 bp linker, `synthDomainB` (130 residues, in frame with domain A, ending in a stop) and 26 bp of overlap with the vector.                                                                                                                                            |
| [GB-bad-Insert2.gb](files/GB-bad-Insert2.gb)                                                       | `GB-Insert2` with one base of its 30 bp overlap changed (449 bp): the panel finds nothing that follows `GB-Insert1`.                                                                                                                                                                      |
| [pIF-Vector.gb](files/pIF-Vector.gb)                                                               | Circular 1,446 bp vector for [In-Fusion and NEBuilder](in-fusion.md): `KanR` (stand-in), `ori`, `synthetic promoter`, one EcoRV site (blunt), `synthetic terminator`.                                                                                                                     |
| [IF-gene.gb](files/IF-gene.gb)                                                                     | Linear 603 bp `synthProt`, a plain ORF (ATG to stop, 200 residues) with no EcoRV site and no cloning ends, for [In-Fusion and NEBuilder](in-fusion.md): the app designs its primers.                                                                                                      |

Not here: the INS record (`NM_000207`). It is third party data, so you fetch it
yourself in the app, from the NCBI box in the exercise; nothing in these pages
contains it.
